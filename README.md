# Zapret Launcher

Zapret Launcher - графическая оболочка для Windows, которая запускает стратегии из проекта `zapret-discord-youtube` без видимого окна терминала и показывает состояние работы в системном трее.

Программа предназначена для удобного управления готовыми стратегиями `zapret` на Windows: выбор стратегии, запуск, остановка, обновление комплекта и редактирование пользовательских списков доменов/IP.

## Возможности

- Запуск выбранной стратегии одной кнопкой.
- Работа без видимого окна терминала.
- Отображение состояния в системном трее.
- Сворачивание и закрытие окна в трей по умолчанию.
- Контекстное меню в трее: показать окно, запустить выбранную стратегию, остановить, открыть списки, выйти.
- Автоматическая подготовка payload при первом запуске.
- Попытка скачать свежую версию `zapret-discord-youtube` с официального GitHub Releases при первом запуске.
- Ручное обновление payload с GitHub.
- Обновление списка доступных стратегий.
- Редактирование пользовательских списков:
  - `list-general-user.txt` - домены для обхода;
  - `list-exclude-user.txt` - домены-исключения;
  - `ipset-exclude-user.txt` - IP/subnet-исключения.
- Сохранение пользовательских списков при обновлении payload.
- Локальный журнал работы в окне приложения. Журнал не пишется на диск и очищается перед каждым запуском стратегии.
- Низкая фоновая нагрузка: приложение не выполняет постоянные сетевые проверки, а только редко проверяет локальный статус процесса `winws.exe`.

## Как пользоваться

1. Запустите `ZapretLauncher.exe`.
2. Подтвердите запуск от имени администратора, если Windows запросит UAC.
3. Выберите стратегию из списка.
4. Нажмите `Запустить`.
5. Если стратегия не подходит, нажмите `Остановить`, выберите другую стратегию и запустите снова.
6. Для добавления доменов или IP используйте кнопку `Добавить в список`.

## Почему нужны права администратора

`zapret` на Windows использует `winws.exe` и WinDivert для работы с сетевым трафиком. Для такого режима Windows обычно требует права администратора.

## Обновления

Кнопка `Обновить с GitHub` проверяет официальный репозиторий:

https://github.com/Flowseal/zapret-discord-youtube

Если доступна новая версия, приложение скачивает zip-архив из последнего GitHub Release и заменяет локальный payload. Пользовательские списки сохраняются.

Если GitHub недоступен, приложение продолжит работать с уже установленным или встроенным fallback payload.

## Нагрузка на систему

Приложение сделано пассивным:

- не пишет постоянные логи на диск;
- не выполняет постоянные фоновые скачивания;
- проверяет только локальное наличие процесса `winws.exe`;
- сетевой запрос к GitHub выполняется при первом запуске после установки payload или вручную по кнопке обновления.

## Важное предупреждение

Некоторые антивирусы могут реагировать на WinDivert, потому что это драйвер и библиотека для перехвата сетевого трафика. Сам по себе WinDivert используется и легитимными программами, но может классифицироваться как потенциально нежелательный инструмент.

Перед публикацией и распространением проверяйте, что используете payload только из официального репозитория Flowseal и официальных релизов.
