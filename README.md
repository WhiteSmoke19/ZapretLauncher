# Удобная работа с zapret

Этот проект является частью инициативы по созданию простых и понятных инструментов для работы с `zapret` на Windows.

Главная цель - убрать лишнюю ручную рутину вокруг запуска, настройки и обслуживания `zapret`: работу с `.bat` файлами, ручной выбор стратегий, постоянное открытие папок, редактирование списков через блокнот и проверку обновлений вручную.

Я не разрабатываю оригинальный `zapret` и не претендую на авторство первоисточника. Моя задача - сделать работу с уже существующими open-source решениями удобнее для обычного пользователя.

## Что здесь будет

В этом направлении могут появляться разные вспомогательные инструменты:

- графические лаунчеры;
- менеджеры стратегий;
- редакторы пользовательских списков;
- утилиты обновления;
- простые средства диагностики;
- инструкции и готовые сборки для более удобного запуска;
- дополнительные оболочки вокруг существующих решений.

Первый инструмент в этой линейке - Windows GUI launcher для `Flowseal/zapret-discord-youtube`.

## Зачем это нужно

Оригинальные инструменты `zapret` мощные, но для многих пользователей входной порог остается высоким:

- нужно понимать, какой `.bat` файл запускать;
- нужно вручную пробовать разные стратегии;
- окно терминала выглядит непривычно и мешает;
- пользовательские списки приходится редактировать напрямую в файлах;
- обновления нужно искать самостоятельно;
- статус работы не всегда очевиден.

Эта инициатива решает именно пользовательский слой: не меняет саму технологию обхода, а делает управление ей проще.

## Принципы проекта

- Не скрывать первоисточники и авторов.
- Не выдавать чужую работу за свою.
- Ссылаться на оригинальные GitHub-репозитории.
- Сохранять сведения о лицензиях.
- Не перегружать компьютер фоновыми процессами.
- Не писать лишние логи на диск.
- Делать интерфейс понятным без чтения длинных инструкций.
- Оставлять пользователю контроль: запуск, остановка, обновление и списки должны быть доступны явно.

## Текущий инструмент: Zapret Launcher

Zapret Launcher - графическая оболочка для Windows, которая упрощает запуск стратегий из `Flowseal/zapret-discord-youtube`.

Возможности:

- выбор стратегии из списка;
- запуск без видимого окна терминала;
- статус работы в системном трее;
- остановка `winws.exe`;
- обновление payload с GitHub;
- редактирование пользовательских списков;
- сохранение пользовательских списков при обновлении;
- встроенное окно с лицензией и ссылками на первоисточники.

## Дисклеймер

Этот проект является вспомогательной оболочкой и набором улучшений пользовательского опыта. Он не является официальным проектом `zapret`, `Flowseal` или `WinDivert`.

Используйте программу осознанно и проверяйте, какие бинарные файлы вы запускаете. Для payload и обновлений рекомендуется использовать только официальные GitHub Releases первоисточников.
